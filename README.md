# Практическая работа № 1 — Git и Unity

Учебный проект для работы с коммитами, ветками, Pull Request и конфликтом слияния.

Автор: sJIatkey (Tsugan).

Редактор: Unity 6000.3.7f1. Сцена: `Assets/Scenes/GitPractice.unity`.

## Запуск

Добавить папку проекта в Unity Hub, открыть указанную сцену и нажать Play.
Это статическая демонстрационная сцена: управление персонажем не требуется.

## План веток

- `main` — исходная сцена с платформой 4 × 1 × 4.
- `feature/add-platform` — расширение платформы по X и добавление сферы.
- `feature/change-platform` — альтернативное расширение платформы по Z.

Обе ветки меняют строку масштаба одного объекта, поэтому после слияния первой
ветки вторая должна вызвать конфликт. Решение должно сохранить обе правки:
платформу 6 × 1 × 6 и сферу из первой ветки.
